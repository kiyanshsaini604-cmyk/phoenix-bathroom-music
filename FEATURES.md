# Phoenix — Five Best Feature Additions

1. App-like onboarding and first-run setup that guides the device through connecting to the music server, choosing the wake word, and confirming audio levels the first time it is powered in the bathroom.

2. Now playing screen with cover art, artist, title, and progress, plus a simple queue so the device can remember what comes next instead of only playing one track at a time.

3. Multi-source and fallback music behavior so the device can try a primary server, then fall back to a local cache or secondary source when the network or server is unavailable.

4. Context-aware bathroom behavior such as idle dimming, steam-aware display brightness, and graceful handling when the room is quiet or noisy, so the device feels tuned to the space.

5. Visual and sound feedback layer that makes every action feel deliberate: wake confirmation, recognized command summary, seek animation, and clear error states when a request fails.

These are the best additions because they make the device feel complete rather than minimal. Each one adds meaningful build work without turning the project into a phone clone.
